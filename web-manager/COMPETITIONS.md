# โครงสร้างรายการแข่งขัน

ติดตั้ง `supabase/migrations/005_competition_structure.sql` หลังไฟล์ 001–004 (002 เป็นที่เก็บโลโก้) ใน Supabase SQL Editor ก่อนเปิดใช้งานเวอร์ชันนี้ ไฟล์ 005 ทำงานใน transaction; ไม่ลบข้อมูลรายการเดิม และคงสิทธิ์ข้อมูลตามเจ้าของบัญชี

## ตัวอย่าง IFC LEAGUE

1. เพิ่มรายการหลัก IFC LEAGUE เลือก “จัดต่อเนื่องหลายฤดูกาล” และระบุฤดูกาล เช่น 2569
2. กด “เพิ่มรอบ / จังหวัด” สร้างรายการจังหวัดต่าง ๆ และ Champions League ภายใต้ IFC LEAGUE 2569
3. แต่ละรอบเลือกลีก น็อกเอาต์ หรือแบ่งกลุ่มแล้วน็อกเอาต์ได้อิสระ พร้อมคะแนนชนะ/เสมอ/แพ้และวันจัด
4. แก้ไขรอบจังหวัด กำหนดปลายทางเป็น Champions League และจำนวนทีมผ่านของจังหวัดนั้น
5. ลงทะเบียนทีมในแต่ละจังหวัด จากนั้นไปโปรแกรม เลือกรอบจังหวัด กด “สร้างโปรแกรม / รอบถัดไป”
6. เมื่อผลรอบจังหวัดครบ ผู้จัดตรวจเกณฑ์ตัดสิน กด “ยืนยันทีมผ่านเข้ารอบ” และเลือกทีม ระบบเพิ่มทีมเดิมเข้ารอบปลายทางโดยไม่คัดลอกหรือย้ายสถิติเดิม
7. หลังรับทีมจากทุกจังหวัดครบ สร้างโปรแกรม Champions League
8. ปีถัดไปกด “สร้างฤดูกาลใหม่” ที่รายการหลัก ระบบคัดลอกรอบย่อยและเส้นทางเข้ารอบภายในรายการ เลือกคัดลอกทีมได้ โปรแกรม ผล สถิติ วันแข่งขัน และสถานะเปิดเผยเริ่มใหม่

รายการจัดครั้งเดียวเลือก “จัดครั้งเดียว” ได้ ไม่จำเป็นต้องมีรอบย่อย รายการเก่าคงเป็นลีกเดี่ยวจนผู้จัดกำหนดโครงสร้าง

## การสร้างโปรแกรม

- ลีก: พบกันหนึ่งเลกหรือเหย้า–เยือน กำหนดวันเริ่มและระยะห่างรอบ
- แบ่งกลุ่ม: กำหนดจำนวนกลุ่มและจัดทีมเข้ากลุ่มเอง อย่างน้อย 2 ทีมต่อกลุ่ม ตารางแยกกลุ่มและไม่นับนัดน็อกเอาต์รวม หลังผลครบเลือกจำนวนทีมผ่านแต่ละกลุ่มได้เอง พร้อมลำดับจัดคู่
- น็อกเอาต์: กำหนดลำดับทีม ตรวจคู่แข่งขันก่อนบันทึก ระบบให้สิทธิ์ผ่านรอบแรกตามลำดับเมื่อจำนวนทีมไม่เป็น 2, 4, 8, 16… หลังผลครบยืนยันผู้ชนะเพื่อสร้างรอบต่อไป นัดเสมอต้องเลือกผู้ชนะตามผลต่อเวลา/จุดโทษเอง รอบชิงเป็นรอบสุดท้าย
- นัดในรอบเดียวกันใช้เวลาเริ่มเดียวกัน แก้เวลาและสนามแต่ละนัดได้ รวมถึงเพิ่มคู่แข่งขันเอง
- ทีมผ่านเข้ารอบจะไม่ถูกคาดเดาอัตโนมัติจากอันดับเมื่อคะแนนเท่ากัน ผู้จัดต้องยืนยันตามกติกา การแก้ผลย้อนหลังหลังสร้างรอบถัดไปไม่เปลี่ยนคู่ที่สร้างแล้ว
- เมื่อมีโปรแกรมแล้ว ระบบห้ามเปลี่ยนรูปแบบ จำนวนกลุ่ม ฤดูกาล และรายการแม่ เพื่อรักษาประวัติ การรับทีมเข้ารอบปลายทางต้องทำก่อนปลายทางมีโปรแกรม
- แต่ละรอบเปิดสาธารณะแยกกัน ข้อมูลที่ไม่เปิดเผยยังไม่แสดงให้ผู้ชม หน้าสาธารณะเลือกดูฤดูกาลและรอบได้จากรายการ

## ตรวจสอบ

`npm test` ทดสอบสิทธิ์ฐานข้อมูล โครงสร้างไม่วนซ้ำ คัดลอกฤดูกาล ส่งทีม สร้างโปรแกรมไม่ซ้ำ ทีมผ่านรอบแรก 2–65 ทีม และตารางกลุ่ม

`npm run test:e2e` ทดสอบบน Chromium กับฐานข้อมูล PostgreSQL จำลองในเครื่อง รวมถึงสร้าง IFC / จังหวัด / ฤดูกาลใหม่ และสร้างน็อกเอาต์รอบถัดไป ไม่ล็อกอินบัญชี Supabase จริง
